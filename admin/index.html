Make the most of your admin

  1. Write in New post — use the live preview, then Download or Save draft.
  2. Commit the .md to _posts/YYYY-MM-DD-slug.md and push to main.
  3. Verify in the Actions tab — the “Deploy Jekyll” workflow should be green.

Help
Tips for authors

              

                
Markdown is rendered with Kramdown (GFM). Use ``` fences for code — they get copy buttons and syntax highlighting automatically.

                
Images: commit to assets/images/ and reference as ![alt](/assets/images/name.png).

                
Drafts: keep posts in _drafts/ (no date needed) and preview with bundle exec jekyll serve --drafts.

                
Security: remove or protect /admin/ before sharing the site — this panel is only a demo gate.
